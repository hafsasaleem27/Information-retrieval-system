# Information-retrieval-system
An end-to-end IR system created for Assignment 3 of Information Retrieval and Text Mining.

- Install nltk using the following command:
pip install nltk

- Now do the following steps:
1. Go to terminal and write 'python'. A python terminal will be opened.
2. Write the following in the terminal step-by-step:
   - import nltk
   - nltk.download('wordnet')
   - nltk.download('punkt')
   - nltk.download('stopwords')
